# Welcome to Modern Reader

This short guide explains the buttons on the Diptyx e-reader. You can open it again from **Settings → Controls guide**.

## In the library

- **Up / Down:** move through books and menus.
- **Center:** open the selected book or menu.
- **Left page:** go back to the previous menu.
- **Right page:** add or remove a favorite when a book is selected.
- **Arrow left / right:** choose a library search filter while searching.

## While reading

- **Right page:** turn to the next spread.
- **Left page:** return to the previous spread.
- **Center or Up:** open the quick menu.
- **Down:** add or remove a bookmark on the current spread.

## Chapters and the quick menu

- In the chapter list, **Up / Down** moves the selection. Double-tap Up or Down to move a screen at a time.
- **Center** or **Right page** opens the selected chapter. **Left page** returns to the quick menu.
- In the quick menu, use **Left page / Right page** to move between sections, **Up / Down** to select an item, and **Center** to open or change it.

## Find books

Choose **Find books** on the home screen. Up and Down choose a character, Center adds it, and Left page deletes the last character. Arrow left and right switch between **All books**, **Favorites**, and **Unread**. Right page shows the matching books. Leave the search empty to browse using only the selected filter.

## USB file transfer

Choose **Transfer files**, connect the reader to a computer, and copy books to the SD card. When finished, use the computer's **Eject** or **Safely remove** command for Modern Reader. Wait for the reader to say **Safe to unplug** before disconnecting the cable.

## Finish this guide

Press **Center** at any time to finish the guide and return to the library. You can reopen it later from Settings.
